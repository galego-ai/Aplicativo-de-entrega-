# Deploy Vercel — Painel Lojista CLICK-FOOD

Este projeto deve ser publicado na Vercel a partir do monorepo `galego-ai/Aplicativo-de-entrega-` com **Root Directory** configurada como:

`apps/lojista`

O projeto Vercel correspondente é `click-food-lojista`.

As variáveis públicas do Supabase usadas pelo frontend devem apontar exclusivamente para o projeto CLICK-FOOD. Credenciais Efí, service role e demais segredos de backend não pertencem ao frontend/Vercel e permanecem somente nos Secrets do Supabase.
