# App Cliente CLICK-FOOD

Estrutura reservada para o aplicativo React Native/Expo do cliente.

Módulos previstos: autenticação, endereço, catálogo, carrinho/sacola, checkout, PIX/cartão/dinheiro, acompanhamento do pedido, mapa, chat, fidelidade, avaliações e notificações.

A experiência de compra inclui sacola persistente durante a navegação na loja, contador de itens, total em tempo real e atalho direto para revisar quantidades antes de finalizar o pedido.
