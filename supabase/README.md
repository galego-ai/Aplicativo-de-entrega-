# Supabase do CLICK-FOOD

Este diretório será ligado a um projeto Supabase exclusivo do CLICK-FOOD.

Regras:

- não reutilizar URL, chaves ou banco do CLICK-GO;
- habilitar RLS em todas as tabelas expostas;
- não usar `user_metadata` para autorização;
- não expor `service_role` em frontend;
- criar migrations pelo fluxo oficial do Supabase após o projeto remoto existir;
- validar schema e políticas com advisors antes de consolidar migrations.

A criação do projeto remoto e das migrations será concluída depois da confirmação obrigatória de organização/custo exigida pelo Supabase.
